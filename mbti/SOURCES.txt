Algorithm version: exploratory-fusion-v1
Every base and extension dimension has eight items. Center ratings at 3, apply source direction, average and divide by 2. Average the two modules with fixed 50/50 weights. This is not a trained ensemble. Both modules share provenance and are not independent measures. Display X if the module signs conflict or absolute fused score is at most 0.125. These are editorial uncertainty rules, not validated confidence intervals.
Mini-IPIP is independently reverse-keyed and scored, never mapped to MBTI letters. Each four-item mean is mapped by (mean-1)*25.
No norms, accuracy claims or diagnostic interpretation. Translations and fusion have not been independently validated. Results exist only in page memory.

Future validation requires translation review, cognitive interviews, independent sample testing, item analysis and retest reliability. This release does not collect participant data.

Staged versions: 32 (base only), 64 (base + extension), 84 (+ Mini-IPIP).
Only the selected complete modules are scored. Unanswered modules are never imputed.
Base-only uses the same +/-0.125 boundary display rule; original strict-threshold type is available separately. Switching versions retains answers only in current page memory. Restart clears all versions and returns to the 32-item version.
